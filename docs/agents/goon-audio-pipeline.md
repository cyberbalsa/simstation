### Reconstructed assignment

Audit all playable audio in the pinned Goonstation source, determine what LÖVE
11.5 can play directly, specify necessary conversion and normalization,
recommend streaming/cache/voice policies, and identify licensing and
attribution risk.

## Consolidated findings

### Inventory

- The pinned `sound/` tree contains 4,699 playable files totaling about
  131.5 MB. The exact consolidated audit measured 131,464,656 bytes and
  25,192.149 seconds of playable audio.
- The audit reported 4,683 Ogg Vorbis files, 12 XM files, two MOD files, and
  two S3M files.
- It reported 4,189 mono files and 510 stereo files.
- It identified 29 groups of byte-identical duplicate content.
- The inventory must be regenerated by the importer and treated as canonical
  only when source paths, blob hashes, and byte hashes are recorded.

### Conversion and runtime

- Preserve every upstream source file byte-for-byte in Git LFS.
- Existing valid Vorbis is directly supported by LÖVE and should not be
  subjected to lossy-to-lossy re-encoding.
- Render the 16 tracker-module files once with pinned FFmpeg/libopenmpt to
  48 kHz stereo Vorbis quality 5. Preserve the source, exact command, tool
  versions, output hash, and loop behavior.
- Keep short one-shots static and lazily cached; stream music, ambience,
  advertisements, long speech, and loops.
- Proposed initial limits were a 96 MiB decoded one-shot cache and 64 active
  voices with deterministic priority stealing.
- Reserve voice priority for UI, critical alarms, and speech before ordinary
  gameplay, machinery, and ambience.
- Keep stereo audio non-positional. Spatialize only mono world audio.
- Use station rooms, doors, walls, pressure, and vacuum to influence
  attenuation and filtering.
- Audio is presentation-only. Variant selection derives from a stable
  simulation event ID and must not consume authoritative RNG.
- Loudness analysis should write gain metadata instead of forcing a lossy
  re-encode. The initial targets were approximately −16 LUFS for music,
  −18 LUFS for speech, and −24 LUFS for ambience, with short effects reviewed
  by peak and semantics.

### Rights finding

- Goonstation's pinned root `LICENSE` applies CC BY-NC-SA 3.0 US to the work,
  and the pinned README says all Goonstation contributions use that license
  except that `tgui` is generally MIT unless otherwise specified.
- Goonstation's audio guidelines explicitly discuss externally sourced audio,
  including material from Freesound, and require contributors to inspect and
  preserve upstream attribution.
- Therefore the repository-level license is evidence, but not conclusive proof
  that every upstream sample was originally relicensed correctly.

## Decision disposition

### Accepted

- Fork the complete pinned audio corpus and preserve originals in Git LFS.
- Do not re-encode valid Ogg Vorbis.
- Convert tracker formats at build time with pinned tools.
- Generate stable audio IDs and full source/output provenance.
- Use lazy static caching, streaming, deterministic voice limits, buses,
  captions, and spatial rules.
- Deduplicate stored content without deleting logical aliases.

### Owner-selected risk policy

- Set `rights_basis = "goon-root-license"` by default for imported Goon audio.
- Do not quarantine an asset merely because historical attribution is missing.
- Continue searching history, tags, and pull requests for better attribution.
- If explicit file-specific evidence reveals an incompatible license, fail the
  release and replace, omit, or obtain permission for that asset.
- Record this as an accepted legal/provenance risk, not as a legal conclusion.

### Rejected

- Lossy-to-lossy conversion of existing Vorbis merely for uniformity.
- Loading every clip decoded at startup.
- Positioning stereo sources as if they were mono.
- Letting audio timing or random variants mutate authoritative simulation
  state.
- Silently distributing an asset after explicit incompatible rights evidence
  is found.
