# Legal and provenance policy

Sim Station is a noncommercial, source-available Goonstation derivative. It is
not accurately described as OSI open source while it distributes content under
CC BY-NC-SA.

These documents are project policy and engineering release gates, not legal
advice:

- [`license-architecture.md`](license-architecture.md) defines which license
  applies to each category of work and the obligations imposed on releases.
- [`goon-provenance.md`](goon-provenance.md) defines the pinned source,
  asset-level records, transformations, and update procedure.
- [`audio-rights-risk.md`](audio-rights-risk.md) records the project owner's
  selected root-license reliance policy and its residual risk.
- [`notices-and-sbom.md`](notices-and-sbom.md) defines generated notices,
  license bundles, asset provenance, and SPDX SBOM release artifacts.
- [`contributions-and-naming.md`](contributions-and-naming.md) defines incoming
  contribution licensing and the temporary codename policy.

Before the first public release, a qualified attorney should review the direct
Goonstation reuse plan, especially the audio provenance policy and the
interaction between ShareAlike content and the project distribution.
